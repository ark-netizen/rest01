## 1. 작업 목표

GitHub 저장소에 올린 이력서(docx)와 사진을 기반으로,  
외부 공유 가능한 개인 포트폴리오 웹사이트를 처음부터 제작·배포한다.

## 2. 작업 내역 (시간 순)

### Phase 1 — 프로젝트 셋업
- GitHub 리포지토리(`rest01`) 클론
- 프로젝트 디렉터리 구조 생성 (`css/`, `js/`, `assets/img/`)
- `.gitignore` 작성
- GitHub Actions 자동 배포 워크플로우 추가 (`.github/workflows/deploy.yml`)
  - `main` 브랜치 push 시 GitHub Pages 자동 빌드·배포

### Phase 2 — 이력서 파싱 및 콘텐츠 적용
- GitHub에 업로드된 `이력서.docx` 다운로드
- docx → ZIP 변환 후 `word/document.xml` 파싱으로 텍스트 추출
- 추출 내용을 바탕으로 `index.html` 전체 콘텐츠 작성
  - Hero / About Me / Skills / Experience / Key Projects / Education / Contact
- 프로필 사진(`박수아_id사진.jpg`) GitHub에서 다운로드 후 적용

### Phase 3 — 디자인 개발 (1차)
- 모던 반응형 단일 페이지 레이아웃 구성
- CSS 변수 기반 컬러 시스템 설계
- 네비게이션 바 (스크롤 감지 + 활성 링크 표시)
- Hero 섹션: 프로필 원형 사진 + 이름 + 배지
- About Me: 바이오 텍스트 + 4개 스탯 카드 (2년/ROI/자격증/GPA)
- Skills: 카테고리 카드 (마케팅·데이터·콘텐츠·저작권)
- Experience: 타임라인 레이아웃 (KBS미디어 하이라이트)
- Key Projects: ROI 수치 강조 카드 3개
- Education: 타임라인
- Contact: 링크 카드

### Phase 4 — 콘텐츠 보정 (공개 범위 조정)
- 회사명 익명화 → OO미디어·OO마케팅·OO콘텐츠 등
- 학교명 제거 (About) / OO대학교 (Education 하단 표기)
- 팀·부서명 전체 제거 (회사명만 노출)
- 민감 수치 삭제 (미수채권·정산금 등 내부 데이터)
- 앨범명 익명화 (드라마 제목 제거)
- 직함 "Campaign & Deal Planning Manager" 삭제
- 수습 뱃지 제거
- OPIc IH → **AL · 2026.05** 수정
- 멀티캠퍼스 부트캠프를 Experience → Education으로 이동

### Phase 5 — 디자인 개발 (2차: Hero 및 배경)
- Hero 배경: 4색 블러 블롭 (하늘·라벤더·파랑·핑크) + 애니메이션
- 도트 그리드 패턴 오버레이
- 데코 원형 링 2개 (드리프트 애니메이션)
- 이름 텍스트: 그라디언트 클리핑 효과
- 프로필 사진: 회전 링 애니메이션 + overflow 클리핑으로 줌인
- 플로팅 칩 2개 (OPIc AL · ROI 270%+)
- Hero 사이즈 반복 조정 (사용자 피드백 반영)
- Hero 콘텐츠 정렬을 About Me의 container 너비(1060px/28px)와 동일하게 맞춤

### Phase 6 — JavaScript 인터랙션
- **파티클 시스템**: Canvas API로 32개 보라색 점 유영
- **타이프라이터**: tagline 텍스트 한 글자씩 타이핑 (BR 태그 보존)
- **마우스 패럴랙스**: mousemove 이벤트로 사진·텍스트 레이어 분리 이동 (lerp 보간)
- **숫자 카운터**: IntersectionObserver로 About 스탯 카드 진입 시 0→목표값 ease-out 애니메이션
- 스크롤 페이드인 (섹션별 순차)
- 활성 네비 링크 자동 표시

### Phase 7 — 컬러 테마 시스템 구축
- `style.css`에서 하드코딩 색상 전부 제거 → CSS 변수화
- **5개 팔레트 CSS 파일** 분리 (`css/palettes/`)
  | 파일 | 조합 |
  |------|------|
  | sky.css | 하늘색 + 앰버 옐로우 (기본) |
  | navy.css | 다크 네이비 + 로열 블루 |
  | forest.css | 다크 그린 + 연두 |
  | royal.css | 딥 퍼플 + 라벤더 |
  | teal.css | 다크 틸 + 사이언 |
- 각 파일에 **라이트/다크 모드** 변수 이중 정의
  - `@media (prefers-color-scheme: dark)` (시스템 자동)
  - `html[data-theme="dark"]` (수동 강제)
  - `:root:not([data-theme="light"])` (라이트 강제 시 다크 미적용)

### Phase 8 — 테마바 UI
- 상단 우측 고정 테마바 구현
- 팔레트 도트 5개 (클릭 → 즉시 테마 전환)
- 다크 / 라이트 / 시스템 3단계 모드 토글 버튼 (아이콘: 🌙/☀️/🖥️)
- localStorage로 선택값 영구 저장 (새로고침 유지)

### Phase 9 — SEO·공유 최적화
- **OG 이미지 생성**: Windows PowerShell의 `System.Drawing` API로 1200×630 PNG 직접 드로잉
  - 다크 네이비 배경 + 도트 그리드 + 데코 링
  - "엔터테인먼트 × 데이터 마케팅 기획자 박수아" 텍스트 레이아웃
  - 역량 뱃지 칩 4개 (둥근 모서리 직접 PathArc로 구현)
- **파비콘 PNG** 32px (탭) + 180px (애플 터치)
- **카카오톡 전용 OG 태그** 완성 (og:type, og:site_name, og:locale 포함)
- Twitter Card 태그
- `noimageindex` 로봇 태그 (프로필 사진 미리보기 차단)

## 5. 이슈 및 해결

| 이슈 | 원인 | 해결 |
|------|------|------|
| Hero 너무 큰 느낌 | `min-height: 100vh` 고정 | `flex-direction: column` + 패딩 조절로 컨텐츠 중심 높이 |
| 히어로-About 정렬 불일치 | 히어로 섹션 자체 28px + hero-content 28px 이중 패딩 | 섹션 좌우 패딩 제거, hero-content에서만 28px 관리 |
| Scroll 힌트 텍스트 겹침 | `position: absolute` + 고정 높이 없음 | flex column + 자연 플로우로 변경 |
| 링크 공유 시 프로필 사진 노출 | 크롤러가 가장 큰 img 자동 선택 | og:image PNG 명시 + `noimageindex` 메타 태그 |
| CSS 변수 없이 다크모드 충돌 | 팔레트 `@media dark` + JS `data-theme` 중복 | `:root:not([data-theme="light"])` 조건으로 분리 |
| 임시 파일 커밋 | git add -A 사용 | `.gitignore` 보완 + git rm --cached 정리 |
